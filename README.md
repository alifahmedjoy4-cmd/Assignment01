# University Management System

## Description

This project demonstrates important Object-Oriented Programming concepts in Java including:

* Abstract Class
* Multilevel Inheritance
* Runtime Polymorphism
* Safe Downcasting

## Technologies Used

* Java
* OOP Principles

## Classes Used

* UniversityMember
* Employee
* AcademicStaff
* Professor
* AdministrativeOfficer
* Main

## How to Run

1. Open the project in VS Code or Terminal.
2. Compile all Java files.
3. Run `Main.java`.

## Features

* Personnel management system
* Dynamic method binding
* Safe downcasting using `instanceof`
* Reusable class design
